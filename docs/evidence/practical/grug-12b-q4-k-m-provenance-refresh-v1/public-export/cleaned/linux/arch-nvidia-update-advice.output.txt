Here is a practical, conservative update checklist for an Arch Linux system with NVIDIA and Wayland:

### 1. Pre-Update Checks
*   **Read Arch News:** Check the [Arch Linux News](https://archlinux.news/) before upgrading. This is the official source for critical changes, breaking news, or required manual interventions.
*   **Check System Health:** Ensure your current system is stable and no critical services are failing before introducing changes.

### 2. Update Execution
*   **Full System Upgrade:** Run `pacman -Syu` to update all packages simultaneously.
*   **Avoid Partial Upgrades:** Never run `pacman -Sy` followed by `pacman -S package_name`. This can lead to broken dependencies and a non-bootable system.

### 3. NVIDIA/Wayland Specifics
*   **NVIDIA Kernel Module:** If a new kernel is installed, ensure the NVIDIA kernel modules are rebuilt for it.
*   **Wayland Compatibility:** Check for any known issues with the specific NVIDIA driver version and your Wayland compositor.

### 4. Rollback and Recovery
*   **Create a Timeshift Snapshot:** Take a system snapshot before updating. This allows for a quick rollback if something breaks.
*   **Keep a Live USB:** Always have a bootable Arch Linux live USB handy for emergency repairs or system recovery.

### 5. Post-Update Verification
*   **Verify Desktop Environment:** Ensure your desktop environment and Wayland compositor start correctly after the update.
*   **Check Logs:** Review system logs (`journalctl -p 3 -b 0`) for any errors or warnings.

### Summary Checklist
- [ ] Read Arch News
- [ ] Create Timeshift snapshot
- [ ] Run `pacman -Syu`
- [ ] Verify NVIDIA/Wayland functionality
- [ ] Check system logs for errors
